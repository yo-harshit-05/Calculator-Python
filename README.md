# Python Calculator Project

A simple menu-driven calculator built using Python.  
This project performs basic and advanced mathematical operations using functions, loops, conditions, and the `math` module.

---

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Floor Division
- Square
- Square Root
- Factorial
- Percentage Calculation
- Menu-driven Interface
- Continuous Execution using Loop
- Error Handling for Division by Zero

---

## Technologies Used

- Python
- Math Module

This project helped in practicing:

- Variables & Data Types

## How to Run

1. Install Python on your system.
2. Save the file as `calculator.py`
3. Open terminal or command prompt.
4. Run the command:

```bash
python calculator.py
```

---
