How to Run

Install Python on your system.
Save the file as calculator.py
Open terminal or command prompt.
Run the command:
python calculator.py
Sample Menu
1 -> Addition
2 -> Subtract
3 -> Multiply
4 -> Divide
5 -> Floor Division
6 -> Square
7 -> Square Root
8 -> Factorial
9 -> Percentage
10 -> Exit
